# N.E.K.O RimWorld Bridge 使用说明

将当前殖民地连接到 N.E.K.O，通过对话询问殖民者、资源、研究、任务、贸易和商队行程，并获取建议。Mod 只读取游戏信息，不执行游戏命令。

## 使用前准备

- RimWorld **1.6**。当前构建引用 1.6.4871；其他游戏版本尚未认证。
- [Harmony](https://github.com/pardeike/HarmonyRimWorld)。在游戏 Mod 列表中将 Harmony 放在 Core 和依赖它的 Mod 前面。
- 已安装 N.E.K.O，以及与此 Mod 配套的 **N.E.K.O RimWorld 插件包**（`.neko-plugin`）。Mod ZIP 与插件包分别安装；bench 不需要安装。
- 用于插件独立咨询的 OpenAI 兼容模型服务。咨询会向该服务发送相关游戏信息，并可能产生费用。

## 安装 Mod

1. 退出游戏，解压 `NekoRimWorld-3.2.0.zip`。
2. 将解压得到的 `NekoRimWorld` 文件夹放进游戏安装目录的 `Mods` 文件夹。
3. 检查安装后的路径为 `RimWorld/Mods/NekoRimWorld/About/About.xml`。
4. 启动游戏，在 Mod 列表中启用 Harmony 和 **N.E.K.O RimWorld Bridge**，按提示重启。

发行 ZIP 已包含运行 DLL，玩家无需安装 .NET SDK 或自行编译。游戏本体、Harmony 和插件单独安装。

## 安装插件并配对

1. 在 N.E.K.O 的**插件中心**选择**导入**，导入 `.neko-plugin` 文件。安装完成后启动 RimWorld 插件；它默认不会自动启动。
2. 在游戏的 Mod 设置中打开 **N.E.K.O RimWorld Bridge**，点击**生成新配对码**，然后勾选**启用 N.E.K.O 连接**。
3. 记下**连接端口**和**配对码**，关闭该设置窗口以保存并应用。
4. 打开 N.E.K.O RimWorld 插件面板的**设置**，填写相同端口和配对码，点击**保存并应用连接设置**。
5. 载入殖民地。面板显示**游戏已连接**后，可以通过调试页的连接检查读取殖民地概况；这个检查不调用模型。

游戏设置会跟随 RimWorld 的语言，提供简体中文和英文；插件面板跟随 N.E.K.O 的语言。端口默认是 `48919`，连接仅发生在本机 `127.0.0.1`。重新生成游戏配对码后，需要同步更新插件设置。

## 配置模型并开始提问

在插件设置的**模型服务**中填写服务地址、模型名称和 API key，点击**保存模型设置**，等待保存结果。它不会自动继承 N.E.K.O 角色使用的模型；高级设置通常可保留默认值。

回到 N.E.K.O 对话，试着问：

> 帮我看看 RimWorld 里，现在最该先处理什么？

在插件面板的**最近建议**中展开完整回答，也可以在**历史记录**中查找以前的讨论。保存设置、浏览历史和检查连接不会调用模型。游戏暂停时也可以咨询。

## 连接或保存没有完成时

- **正在连接／正在重连**：确认插件已经启动，并已保存相同的端口和配对码。
- **正在核对配对码**：等待连接完成；若一直无法连接，请重新核对两端设置。
- **配对码太短**：使用游戏中的生成按钮，然后重新启用连接并关闭设置窗口保存。
- **保存结果尚未确认**：先核对同一次保存的状态。插件重启后，旧回执可能无法恢复；检查当前配置后再决定是否重新保存。页面不会自动重复写入。
- **没有完整回答或文件导出失败**：先阅读面板保留的正文和说明，完整回答仍可复制；不要仅为保存回答而重复咨询。

配对码和 API key 请妥善保管。分享截图或日志时，遮去这些内容。

## 更新

退出游戏并停止插件后，将旧 Mod 文件夹移到游戏目录外备份，再放入新版本的 `NekoRimWorld` 文件夹。保持安装文件夹名称一致，并核对 Mod 与插件的配套版本。已有游戏设置和插件历史不在 Mod ZIP 中。

## 包内信息

`BUILD.json` 记录构建版本、输入哈希、依赖及软件烟测结果；`THIRD-PARTY-NOTICES.md` 和 `Licenses/` 保留运行依赖的许可证。ZIP 随附的 `.sha256` 和 `.manifest.json` 可用于核对下载及解压内容。

软件构建和烟测不代表所有 Mod 组合、操作系统或实际咨询质量都经过认证。
